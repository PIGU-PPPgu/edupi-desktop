EduPi Desktop 0.3.105，macOS Apple Silicon 预发布。

电脑操作工具的提示和状态回执明确区分权限检查与屏幕观察，指向原生 `observe` 操作。已配置的智学网工具在同一教师请求中将登录与同步各限制为一次，防止反复弹窗或重复刷新。

工具返回的图片现在直接出现在对话中，可从右侧放大。二维码可在扫码窗口中查看；HTML 与 Mermaid 图形可在对话中预览，也可打开右侧预览栏，无需图片模型。同一条请求重复启动智学网登录窗口会被拦截。

修复 macOS 安装版中 HTML/SVG 预览空白：内嵌无权限预览允许 WebKit 的内部 `about:srcdoc` 导航，外部导航仍拦截。
修复 SVG 尺寸和坐标被 HTML 清洗误删导致图形失真；脚本与外链继续被拦截。

AI 协作的本机文件和图片可从对话打开到右侧预览，选择产物后收起产物菜单。
AI 返回的图片内容块会在对话内显示，点开后可在右侧查看。

AI 协作在聊天顶部显示可收起的实际执行阶段。明确请求工作流时，用户确认后可运行并行只读子任务；成功和失败分支、最多三轮重试及中断续跑都有调用上限。拟稿结果待审，不直接写入教师资料。

取消或受阻的工作流不会再显示为已完成。

当前源码配对 Core `008d3e63cc1ab4fa2adfba4817241720408dc6fb`。新增的 Core 自选来源查询仍仅供 owner 只读诊断，不构成模型回答授权；复合回答保持拦截。

仅提供 macOS Apple Silicon 安装包；Windows/Linux 延后，正式自动更新源不切换。
