EduPi Desktop 0.3.68 签名试用候选。

0.3.67 的三平台构建产出九项资产，Apple 公证 Accepted，DMG 装订、首次校验和 Gatekeeper 通过；最终重复校验时 CloudKit 连接中断（`-1005`），导致 Mac job 失败且资产证明跳过。本候选仅让该明确的 Apple 票据服务瞬断最多重试两次；错误持续或票据、签名失败仍停止。Core 仍固定 `b12b5cbfd6f26561c535a95bfbf692fbe5fdae2d`，产品功能与 0.3.64 相同，短暂断连横幅尚未修复。三平台构建通过不等于安装验收或公开更新；原位升级、App 管理权限、真实跨到期睡眠、真人教学质量和 Windows/Linux 完整教师流程仍需分别验收。

- RustSec 2026-10-14 新公告涉及锁定的 rustls 0.23.45；本候选锁定官方修复版 0.23.46，不忽略审计告警。最终 Rust 审计和跨平台构建仍以 CI 实际结果为准。

- 冷启动连接检查改读桌面壳启动前已验证的轻量身份端点，避免用较慢的普通页面 API 判定服务离线。真实提醒的 Core 来源证明继续逐次核验，按根校验耗时设置分层有界时限；超时仍拒绝发送，不自动重试未知结果。

- 修复任务内新会话的草稿与发送标识错位；打开任务时先验证工作区，让本地模型在发送前可选。安全模式的模型与 Skill 读取不再加载第三方扩展；第三方文件仍保留，恢复正常模式后可继续使用。

- 暂存集成与 Windows 隔离安装烟测增加脱敏失败诊断，教师上下文的单次写入等待上限延至 45 秒；不自动重试未知结果，不放宽 Core 或 Safe Mode 准入。

- Core 固定为 `b12b5cbfd6f26561c535a95bfbf692fbe5fdae2d`，Pi 与 PiDurable 仍为 1.0.2。Core PR #279/#280 增加本地 L4 使用证据与版本化教师同意；Runtime schema 和 Core runtime 清单已变，Desktop 组件清单、Bridge v1.1 的 12 个公开命令未变。Desktop 尚未接线新的 `teacher_usage` 同意、记录、读取和上传批次读取 API，默认不采集或上传；Core 隔离测试证实没有外发。
- Core 在法定假期和未映射的调休工作日不推断课次；已核实的教师手动课次继续保留。旧草稿与审核历史不会因来源失效被当作可执行的新任务。
- 家校观察仅展示明确学生身份、来源和修订历史。未核实的监护身份、关系好坏与 G5 授权不会由一条记录推断。
- 备课任务读取 Core 的真实阶段、attempt、历史和取消/重试权限；未知子代理数量和总步骤不编造。来源变化后旧任务 revision 拒绝继续操作。
- 桌面端修复重复发送、提醒恢复、授权状态和过期事项的前台时效；工作区与“今天”按当前事项呈现，历史仍可查找。
- 已启用的主动能力先保存跨端口恢复记录与完整 Pi 请求，Core 肯定捕获后才派发 Pi；未知发送结果保留原请求号及原文供教师核对，不自动重复。G2 隔离试用使用 Core 有界模型适配器；DOCX 上传的备课课次建议仅待审，不自动采用或执行。
- 配对 Core 的构建 canary 改用本地合成模型配置与注册回执链，实际穿过生产消息路由并核对 Pi 会话落盘；旧未注册消息入口保持拒写。
- Core 只自动续接可安全执行的请求；自然改期与取消在本候选中不自动改写既有任务，需在后续审核入口完成闭环。
- 新 ICS 日历默认只接入材料；教师预览文件内事项并明确确认后，才按预览指纹将日程写入 Core。过期预览与缺少桌面授权均拒绝采用。
- DOCX 首次接入同样只保存材料；可核对的日程提案由教师另行明确采用，缺失时区等来源问题保持待审。已有来源修订仍使用原指纹绑定。
- 发布仓库迁至 `PIGU-PPPgu/edupi-desktop`。更新检查优先读取新 Raw feed，旧地址作为迁移期回退；签名与校验流程不变。
- G1/G2/G3/G4 Live 保持默认关闭，外部发送仍需既有明确确认。真实睡眠、真人教学质量及各平台安装验收不由源码测试代替。
- 本次先构建三平台签名 Draft。安装验收完成前不公开 Release，也不更新 `updater-feed`。回退时保留教师数据和模型配置，不删除新版账本字段。DOCX 重进刷新、真实跨到期睡眠、真人教学质量和 Windows 权限仍单独待验。
