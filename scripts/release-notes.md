EduPi Desktop 0.3.79 macOS Apple Silicon 技术候选，Release 保持 Draft。

配对当前 Core 的来源支持判别和大历史认证修补。明确数量单位保留数值与单位组合，当前来源没有完整答案时保持空返；取消查询会通知模型进程，后台工作实际完成后才释放容量。修复安装包中模型宿主的相对依赖遗漏和部分来源拒绝原因被整批误挡的问题。

首条消息使用同一个输入框，肯定持久回执只处理对应草稿，迟到回执不清除新任务的编辑。已删除学生的历史记忆在普通路由与压缩前重新核对当前来源；无法证明来源的旧摘要不发送给模型，原会话记录仍保留。

折叠入口统一为细线箭头，保留键盘开合、嵌套记录和原业务状态。连接恢复后可从设置查看本次失败记录；原生屏幕观察保留准确 AX 错误，不把所有失败都误报为未授权。诊断改进不代表屏幕观察已经成功。

修复已接受消息误报待核对、迟到回执清除新编辑草稿、Core 文件缓存抖动，以及合法无回滚审核回执被误判失败。连接详情仅保留本地状态与耗时，不保存消息、令牌或实例值。已写入的评价保留，并重新核对 Core 来源，失效来源不计为当前证据。

原生桌面逐次确认绑定当前应用主窗口，缺少窗口或请求过期立即拒绝。已封存的 Core 技能不可经普通技能开关写入。DOCX 章节建议先读取当前原文与元数据，再由教师明确确认片段，不自动采用或创建备课任务。

ICS、DOCX、PDF、PNG、JPEG 先登记材料，再由 Core 重新读取当前来源；图片正文须单独核对，安排与备课片段仍需明确确认。旧来源更新、逐项配对、取消、EXDATE 和文件课表保持拒绝，历史记录不自动迁移或删除。

Core 精确提交、Runtime schema 和双组件清单以包内兼容清单为准；源码检查、签名、公证与实际安装结果分别记录，不互相替代。教师资料和模型配置保持，外部发送关闭。

本轮只构建 macOS Apple Silicon，不构建 Windows/Linux，不公开 Release 或更新七平台 feed。

Next、DOMPurify、Zod、Undici、Nodemailer 与原生依赖已完成源码安全修补，Pi 与 React 版本保持。源码审计、签名与安装技术证据分别记录。

OpenConnector 的 MCP client/server 固定2.3.0，自有 REST 请求不跟随重定向，避免凭据正文或自定义请求头流向其他来源；目录和控制台仍不开放 MCP 服务端入口或外部动作。

TLS 依赖精确更新为 rustls-webpki0.103.16 与 webpki-root-certs1.0.10。官方解析、版本回归和 Mac normal/build 闭包已核对；不从依赖存在推断历史漏洞已可利用。

Rust ZIP 依赖与停止维护告警已完成源码处理，Mac 签名前仍检查目标依赖闭包。Windows 本轮不构建，不以源码审计代替实机证据。

Live 能力默认关闭，技术测试只在明确隔离的合成根启用。本地用量默认不收集，未配置正式政策和协议时拒绝开启；没有云端上传接线。
