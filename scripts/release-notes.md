EduPi Desktop 0.3.77 macOS Apple Silicon 技术候选，Release 保持 Draft。

修复已接受消息误报待核对、迟到回执清除新编辑草稿、Core 文件缓存抖动，以及合法无回滚审核回执被误判失败。连接详情仅保留本地状态与耗时，不保存消息、令牌或实例值。已写入的评价保留，并重新核对 Core 来源，失效来源不计为当前证据。

原生桌面逐次确认绑定当前应用主窗口，缺少窗口或请求过期立即拒绝。已封存的 Core 技能不可经普通技能开关写入。DOCX 章节建议先读取当前原文与元数据，再由教师明确确认片段，不自动采用或创建备课任务。

ICS、DOCX 先登记材料，再由 Core 重新读取当前来源，明确确认后采用安排。PDF、图片、OCR 与旧 .doc 只收件，不写入日程或课表。旧来源更新、逐项配对、取消、EXDATE 和文件课表尚无 owner 合同，入口拒绝并保留暂存，历史记录不自动迁移或删除。这些限制不计为更新功能完成；Core 写入围栏与安装负例须在最终配对中单独通过。

Core 精确提交、Runtime schema 和双组件清单以包内兼容清单为准；源码检查、签名、公证与实际安装结果分别记录，不互相替代。教师资料和模型配置保持，外部发送关闭。

本轮只构建 macOS Apple Silicon，不构建 Windows/Linux，不公开 Release 或更新七平台 feed；公开版仍为 v0.3.70。

OpenConnector 的 MCP client/server 固定2.3.0，自有 REST 请求不跟随重定向，避免凭据正文或自定义请求头流向其他来源；目录和控制台仍不开放 MCP 服务端入口或外部动作。

TLS 依赖精确更新为 rustls-webpki0.103.16 与 webpki-root-certs1.0.10。官方解析、版本回归和 Mac normal/build 闭包已核对；不从依赖存在推断历史漏洞已可利用。

仓库级 Rust 审计仍报告 zip 4.6.1 的三项漏洞。该依赖由 Tauri updater 的 Windows 目标引入，官方修复要求 zip 9，现有约束没有兼容锁版修复。Mac 签名前必须通过目标依赖闭包检查，排除 zip 9 以前的版本；此门不等于仓库审计通过，也不证明 Windows 安全。

Live 能力默认关闭，技术测试只在明确隔离的合成根启用。本地用量默认不收集，未配置正式政策和协议时拒绝开启；没有云端上传接线。
