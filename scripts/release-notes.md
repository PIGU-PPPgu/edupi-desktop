EduPi Desktop 0.3.93，macOS Apple Silicon 技术候选。

首次打开保留全屏持续可见的手写“Welcome To Edupi”，由 EduPi 介绍自己、想怎样帮助老师，以及希望老师有时间留给学生和自己。本地手写字体加载超时会回退，窄窗与减少动态效果下保持操作可达。

配对 Core `42d464ed`。复合记忆召回无法逐项证明来源时保持待核验，不拼接部分答案；沿用 PDF 可见来源限时重试及来源、owner、时间围栏。图片正文和日程仍由教师分别确认。

全新资料根导入行事历后，教师可明确点击“建立本机身份”读取安排提案；该动作只创建当前根的 Core owner，不自动启用主动运行或采用日程。安排仍需独立确认，采用回执与日程在重启后重新核对。

首次使用界面改为全屏玻璃欢迎画面，同一预览面板在引导和原位表单之间连续变形；放大操作字号，并修复表单聚焦造成舞台裁切。继承 Core `f599fc38` 引入的现行教学题召回限定，保留原 Bridge、Runtime schema 与教师确认边界。Mac 签名流程在 App 公证后核实并补齐票据，再从同一 App 验证 DMG 与更新包签名和字节身份。

首次设置可在引导中直接连接通用 API 模型、填写教师资料、导入学生名单与行事历。名单模糊列名可在桌面端请求 AI 建议，汇总行须排除后才能确认导入；写入后核对特征、家校备注与班级。行事历材料先接收与预览，安排仍须教师确认。模型配置和可能调用模型的接口在打包版要求桌面进程令牌，教育自动任务拒绝 Coding Plan 端点。

首次使用引导增加欢迎画面、逐步功能预览与可暂离的检查栏，进入功能页时保留页面标题和操作区域。提醒状态、日程内容与视图、工作区分类改用 affectUI 免费 MIT 分段控件，支持方向键、窄窗滚动和减少动态效果；保留原详情重选行为。

主导航收起时立即应用窄栏宽度，并保留原先的展开操作。统一首页、设置、管理中心和工作页面的最新界面修复，接入新的品牌图形、页面层级与减少动态效果支持。保留真实运行版本与权限状态核对，改进聊天草稿续接、表单提交回执、历史版本选择和键盘焦点。

配对固定 Core 主线与日程备注、审核身份修补。召回继续核对当前来源、明确数量单位和班级学期范围；缺少完整答案保持空返，取消后等待后台实际回收。材料图片仍须独立核对正文，安排与备课来源仍需明确确认。

升级前来源仍可完整核对的备课产物保留只读历史；同一条教师消息的相同记忆调用复用回执，避免重复落盘。

记忆写入、遗忘与学生记录的执行回执在当前轮保留；历史来源失效时仍隔离旧回复，回执不授予后续轮次或压缩永久记忆权威。
