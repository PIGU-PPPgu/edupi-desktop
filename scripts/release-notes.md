EduPi Desktop 0.3.121，macOS Apple Silicon Release。

本版本只发布 macOS Apple Silicon 资产。Windows、Linux 和其他平台没有构建，也没有上传。

Core 固定到 `fc89b3bc899a55b0fdad61b8f37e238d950f37c6`。版本包含智学网扫码登录桥接和可配置的基础学情同步桥接。同步配置由老师提供班级、学科代码和学段代码，结果写入当前用户数据根，使用独占锁和原子状态文件，登录失效、空结果、重复运行与网络失败均明确报告。智学网登录现在会等待浏览器、token 探测和二维码图片的有界启动窗口，避免慢速启动时首条结果没有二维码。

真实智学网账号扫码、登录态跨冷启动续接和真实学情抓取仍需要实际账号验收。Rust chrono 维护告警已通过锁文件和本地补丁移除，Windows UIA 编译与运行继续保持未验收边界。

本 Release 不宣称完整 R04 或 L4 已通过。
