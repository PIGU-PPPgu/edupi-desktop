# 学生网络第一段：有来源的学习与互动记录

实现：Core students 操作增加 record_events/list_events/update_event/delete_event；对话工具从会话取真实教师消息作为来源。学习与互动分开存储，分页返回；修改保留历史，删除为撤回，同一来源重试不复活。

Desktop 班级页提供记录入口，选中学生后在档案抽屉内显示记录。可以筛选、手动修改、删除、回看原始对话；AI 可查询、记录和修订，工具完成后刷新列表。

验证：Core store、bridge、Desktop 配对 E2 通过。真实隔离对话产生学习和互动各一条；首次模型误省略测试姓名前缀被拒绝，明确完整姓名后写入。浏览器手动修改成功并出现历史；互动记录删除后列表为空。真实学生数据未写入测试记录。

范围：本段是网络的证据记录基础，不是大规模图谱页面。仍使用现有名单的唯一姓名键；跨班同名、稳定身份迁移、知识点图形布局、时间筛选和课前准备检索这些新记录，仍在后续阶段。不得把该 checkpoint 说成完整知识图谱已上线。
