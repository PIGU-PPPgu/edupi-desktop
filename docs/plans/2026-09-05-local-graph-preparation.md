# 学生局部图与课前证据

本轮交付两条连接：学生—具体记录—知识点的可点击局部图；匹配的学习记录进入课前准备输入。

图谱展示当前记录页中的最多 8 条完整记录、24 名学生。多人事件保留一个事件节点，不生成任意两人之间的好友关系。点学生或主题可看相关记录；点记录或连线打开原记录的编辑、删除、来源和历史。列表保留全部当前页记录，并明确局部图数量。

Core 每节课选取最多 3 条近 30 天的学习记录：班级必须匹配，主题与课次明确 topic 或该学科当前教学重点同名。互动记录不进入学习判断。多班且无归属时不使用；只有课表仅有一个班时允许以该班作为默认归属。名单 CSV/Excel 现在支持班级列，并通过正式导入接口保存。

每条证据包含记录 ID 和 revision；修改或删除改变备课任务的输入指纹，原课次 ID 保持不变，下一次准备检查可识别来源变化。不是即时重写教师已确认的产物。

验证：Core planner/heartbeat/store/port 定向检查通过；集成测试证明正式名单导入的班级参与匹配，且记录进入模型 prompt。Desktop 局部图测试证明多人事件不展开为两两关系、数量受限且不删减已纳入事件的参与者；浏览器连线点击可显示来源与编辑入口。

仍有限制：没有跨班同名身份迁移；知识点目前按名称匹配，没有语义别名或先修知识推断；图不是全校网络；本轮模型输入测试使用确定性模型回调，不声称完成真实课堂质量评估。
