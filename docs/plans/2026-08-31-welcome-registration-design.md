# EduPi 首次欢迎与本机注册设计

## 目标

首次打开 EduPi Desktop 时，不展示产品介绍页。屏幕只完成一件事：以接近新 iPhone 设置完成页的节奏，慢慢写出“欢迎使用 EduPi”，然后让教师输入邀请码进入。

## 首屏

- 全屏近空白画布，不显示粒子、卡片、价值宣言、功能说明或页脚。
- `欢迎使用 EduPi` 位于视觉中心。中文使用系统楷体，英文使用系统手写体；实心字由 SVG 方向蒙版按“欢迎使用 → EduPi”的顺序显现，墨色和背景只做克制的缓慢变化。
- 最后一段蒙版动画结束后，才出现一个邀请码输入框和一个“继续”按钮。预留固定高度，出现时不推动标题。
- 错误、连接和重试均限制为最短可行动文字。
- `prefers-reduced-motion` 下直接显示完整字样和输入框，不等待、不播放动画。
- 320–1440px 共用同一构图，小屏保持单行输入与键盘提交能力；短屏缩小纵向间距。

## 注册边界

- 继续使用既有 `GET/POST /api/edupi/registration` 和本机注册文件，不建立第二套资料或账号体系。
- 邀请验证继续在服务端完成，客户端不保存邀请码。
- 已注册用户由服务端初始状态直接进入工作台，不闪现欢迎页。

## 验证

- 静态约束：注册 Gate 仍包裹 `AppShell`；首屏只保留欢迎字样、邀请码和短操作；旧粒子与说明性内容不能回归。
- 动效约束：书写序列、延后显示、减弱动态模式都有确定实现。
- 质量检查：组件测试、完整测试、TypeScript、lint 和 diff check。
- 运行检查：320、768、1440px；键盘输入/提交；错误、重试、成功离场；控制台无错误。
