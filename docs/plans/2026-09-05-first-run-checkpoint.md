# 第三阶段：实际配置驱动的入门

引导扩展为七步：模型、教师资料、名单、课表、材料、第一次备课、今天。检查并继续读取实际数据：默认可用模型、教师配置、名单、课表、接入材料和课前任务产物。允许主动跳过，不把打开一个页面当成已完成。步骤保存到统一 app-prefs，重新打开可续接。

浏览器验证：七步入口可见；空教师配置检查后仍停在第二步，提示继续设置；刷新后重新打开引导恢复第二步。类型、Lint 与全套 884 通过/16 跳过、0 失败。

第二阶段配套证据：真实模型隔离会话成功建立备课任务；桌面独立准备 worker 已真实运行，校历草稿与逐课准备继续由 Core 产出。最终打包/安装验证在两阶段合并前完成。完整学校试用与 Windows 实机不在这些隔离验证的结论内。
