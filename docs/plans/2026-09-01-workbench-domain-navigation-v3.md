# EduPi Desktop 领域导航 V3

## 目标

把 V2 的“二级栏逐条列对象”纠正为教师熟悉的“二级栏选分类、主区处理分类内容”。课程、学生、记忆、洞察、材料和审核都使用一致的信息层级：领域入口 → 分类/筛选 → 数据表或工作区 → 抽屉详情。

## 信息架构

### 教育记忆

- 二级栏固定为：学期、学生、教学、教师偏好、学校。
- 主区显示所选类别的记忆数据库，8 条/页。
- 每行显示内容、关联对象、标签、累计次数和更新时间；详情折叠展示来源信息。

### 教学

- 二级栏固定为：教学首页、课程表、教学重点、备课任务、教学记忆。
- 所有子页保留“返回教学首页”。
- 首页直接显示本周课程、下一节课、当前重点和待处理准备；次要信息用折叠行。

### 班级

- 二级栏保留可搜索学生名单。
- 主区始终显示按姓名排序的学生图标网格和班级概览。
- 点击主区图标或侧栏学生，从右侧打开档案抽屉；抽屉包含个人信息、学习模式、轨迹、家校记录和关联教育记忆。
- 档案补充通过现有 Core 学生导入接口写回；记忆修订进入教师确认协作，不直接静默覆盖。

### 日程

- 保留汇总/校历/课程表切换。
- 课程表类别直接显示“节次 × 星期一至星期五”网格，共 10 节，第 5/6 节之间有午间分隔。
- 点击课程单元格仍使用右侧详情/编辑抽屉。

### 观察与洞察

- 一级分类：学情观察、班级运行、教学改进、EduPi 后台。
- 二级筛选：全部、已浮出、酝酿中、弱信号。
- 主区使用 Notion/Supabase 风格数据表，列为类型、内容、状态、依据、最近时间；8 条/页，行内折叠详情。

### 成长

- 明确区分“教师专业成长”和“EduPi 能力成长”。
- 教师成长显示过程文档与已确认成果；EduPi 成长显示后台学习主题和能力候选。
- 所有状态中文化，避免抽象英文标签。

### 材料与待确认

- 材料二级栏按全部、教案、练习、评估、课堂记录、其他分类；主区为材料数据库表。
- 材料行打开右侧抽屉，展示来源、分类、关联任务和补充协作入口。
- 待确认首页为任务/观察/记忆三列小看板；进入任务后用纵向步骤导航替代横向 1–5 流程。
- 全部二级侧栏继续支持折叠与窄屏抽屉。

## 实施切片

1. 分类路由与数据库表基础：记忆、洞察、教学二级栏。
2. 教学首页与课程表网格。
3. 班级学生网格与右侧档案抽屉。
4. 成长、材料、待确认与纵向审核流程。

## 验证

- 结构测试锁定分类而非单条对象导航。
- 类型检查、lint、全量测试。
- 浏览器验证桌面与 800px 宽度：分类切换、分页、课程表单元格、学生抽屉、审核看板和侧栏折叠。

## 风险

- 正式教育记忆没有现成的直接修改命令；本轮把修订动作交给现有教师确认协作，不创建 Desktop 本地记忆副本。
- 已接入材料没有独立更新命令；补充内容进入协作/任务证据流程，不伪造本地持久化。
