# R12/R17 学生身份实施约定

状态由 `2026-09-06-product-closure-roadmap.md` 统一记录。本文件只定义兼容方式与验收范围。

- 保留 student_profiles 旧字典 key，旧事件中的 students 继续指向原 key。新同名学生独立 ID 与 key，姓名只用于显示。
- 边界按 student_id 解析。旧裸姓名请求仅在唯一匹配时兼容；跨班同名必须使用 ID 或明确班级。导入另一班的同名人不能猜作转班。
- 旧档案修改前先固定其原有派生 ID。转班沿用 ID，旧事件所属班级保留；未知历史不依据新班级补填。
- 新删除指向 ID。旧姓名删除记录只影响原 legacy key，不能隐藏后来新增的同名学生；不改写历史幂等记录。
- 同步改名单、事件、画像扩展、旧 class.json 同步、学生编辑删除、图节点与相关记录筛选。仅改名单不算完成。

隔离验收使用 A 班张三、B 班张三与李四。覆盖两人独立选择/写入/编辑/删除/图谱，旧来源重放，旧删除记录不影响 B，A 转班后旧事件归属不变、新事件使用新班，裸姓名歧义时不写入，重启后再查询。

并行分工：子任务只实现 Core 身份解析、名单导入和按 ID 更新及测试；父任务负责事件、删除、画像扩展、Desktop 与整体验收。统一完成后更新 Core 配套版本，禁止各自覆盖 manifest。
