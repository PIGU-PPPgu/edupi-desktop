# 对话立即执行指定备课任务

日期：2026-09-06。

## 结果

新增 `edupi_prepare_task`：对话可以先按日期、学科、班级号、节次和标题查找已有课表/校历准备任务，再点名启动一个任务。启动回执只说明运行中；完成状态和产物由后台状态与 Core 执行记录确认。

Core 支持 `requestedTaskId`。教师明确要求时，未来任务可以提前执行；普通整点检查仍按到期时间运行。指定执行只处理目标任务，不把普通手工任务当成可生成工作。相同输入重试复用已有草稿；普通整点检查不会使提前草稿失效。来源或证据修订后仍形成新的输入指纹。

## 验证

- Core：未来目标首次调用模型一次，生成四份草稿；普通检查后再次点名仍复用草稿；不存在的任务返回 task_not_found。
- Desktop：自然语言查询 `2026-10-06 数学 703 班第2节` 命中目标任务，模型依次调用 list 和 prepare，后台状态 running → ready。
- 真实隔离模型：目标未来课次生成四份草稿，执行 attempt=1；第二次直接返回 prepared=0，仍是同一份四产物记录。
- 学生学习记录已包含在该课次输入摘要与 evidence_ids 中；生成产物均围绕移项主题。模型没有在正文重复学生姓名，本证据只证明输入接通及产物生成，不证明课堂质量。
- Core 全套与定向执行测试通过。Desktop 全套与 C2/C3/课前 E2 在最终 pin 上重跑。

## 边界

目前立即执行覆盖已存在的课表/校历准备任务。通过对话新建的普通任务只有任务记录；若要直接生成教案、PPT 等新类型产物，需要下一阶段建立任务模板和产物契约。后台启动后不会被当前对话的停止按钮撤回；停止前未启动的请求会遵循取消信号。
