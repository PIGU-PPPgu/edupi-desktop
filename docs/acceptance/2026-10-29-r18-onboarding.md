## 页面与交互验收

环境：macOS arm64、Node 22.23.1、Next dev 16.4.2、Chromium 156.0.8078.49。独立 `PI_CODING_AGENT_DIR`、`EDUPI_DATA_ROOT`、`EDUPI_PROJECT_ROOT` 启动 `npm run dev`；浏览器把 `/api/edupi/workspace` 替换成合成空工作区，不写教师或学生资料。非本轮目标的 Core API 在隔离环境中可能返回 503，不作为业务验收通过；本轮页面操作期间捕获的 JavaScript `pageerror` 为 0。
