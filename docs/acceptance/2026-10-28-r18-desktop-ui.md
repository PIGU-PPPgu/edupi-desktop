参考用户提供的 `aa53f1ec257370a903626dd17942ddc4.mp4`：960×720、60fps、14.617 秒；全片按 2fps 检视，5–8 秒入场段按 6fps 复查。借鉴浅灰导航、白色工作面、柔和彩色图形、短距离错峰清晰入场。

- `native-theme.css` 统一表面、文本、圆角、阴影和动效 tokens；品牌蓝与主操作墨色分别定义，深色模式有对应颜色。
- 复用 `native-button`、`native-input`、`native-select`。工作台表单接入同一套控件，展开表单时只保留创建按钮为主操作；焦点保留 3px 阴影环，移除重复描边。
- `EduPiBrandMark` 用在导航与聊天入口；简报和日程使用共用 `EduPiSurfaceIcon`。今天只增加真实日期，没有增加说明区块。
- 入场 480ms，区块延迟 0/50/100/140ms；弹窗和抽屉 240ms，控件反馈 160ms。使用 `backwards`，结束后不保留 transform/filter；减少动态效果时取消新增动画及延迟。持久聊天宿主未重挂载。
- 保持 `globals.css` 不变，`edupi-disclosure.css` 仍为最后一项 CSS import。
