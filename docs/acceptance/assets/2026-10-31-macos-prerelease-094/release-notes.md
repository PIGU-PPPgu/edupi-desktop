EduPi Desktop 0.3.94，macOS Apple Silicon 预发布。

[下载 macOS 安装包](https://github.com/PIGU-PPPgu/edupi-desktop/releases/download/v0.3.94/EduPi_0.3.94_aarch64.dmg)

- 全屏手写「Welcome To Edupi」后，EduPi 的三句自我介绍逐字出现；输入过程中可直接开始探索，减少动态效果时立即显示全文。
- 首次引导可连接模型、填写教师资料、上传学生名单和行事历；日程安排预览后由教师确认采用。
- 首页提供快捷入口、常用服务、看板和右上角的新建对话，统一设置与工作页面的样式和交互。
- 配对 Core `d87b44d6`，保留记忆来源核验、教师确认和重启后回读；修复 OpenConnector 依赖中的静态路径双重解码问题。

安装包已通过 Apple 签名、公证和 Gatekeeper 检查。本次仅提供 Apple Silicon Mac 版本，Windows/Linux 暂不发布。

自动更新源仍为 0.3.70，此预发布需手动下载安装。教育自动任务使用通用 API 模型，Coding Plan 端点不用于这些任务。
