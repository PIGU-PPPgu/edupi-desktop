## 范围与身份

- Desktop 源码 `7d961c7`（阶段图起于 `12fa399`，基于 main `a417e70`）；本次未改 Core pin、真实教师数据根、模型凭据、公开更新源或已安装应用。
- 普通 Pi 对话在聊天区上方显示可收起的实际工具调用阶段，不推断子代理或成功状态。明确要求工作流时，Pi 可生成 1–6 个有名称的阶段，每阶段 1–4 个独立子任务；启动前显示全部任务与模型并要求原生确认。
- 确认后，同阶段子任务并行、阶段顺序执行；子会话仅启用 `read/find/grep/ls`，每个子任务有独立 Pi 会话与最终结果。失败或取消会停止后续阶段。私有状态日志只存名称、身份和状态，任务内容与结果保存在 Pi 会话中；客户端按当前用户消息 ID 读取，避免切换会话时显示旧流程。

## 边界

- 这是按用户任务即时生成阶段的工作流，未直接拷贝 ZCode 的独立包及宿主层，也未实现它的条件分支、循环和跨进程续跑。进程异常后的超时日志显示为“已中断”，需要重新启动工作流。
- 子任务只读，不能代替教师确认、资料写入、外部发送或发布；这些仍由主会话既有工具及其原门禁完成。
- 本次没有重新打包或安装客户端。签名安装版的真实会话、确认弹窗和本机外观仍需新候选验证；Windows/Linux 未测。
- Core-first 已捕获父回合的子任务授权链尚未在安装版实际触发，现有验证是代码边界和合成模型调用，不能把该路径记为端到端通过。
